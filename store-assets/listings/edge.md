## Privacy page

- Single purpose: Capture user-requested visible pages and local images into a
  full image editor for non-destructive photo adjustment, layered composition,
  and export.
- Remote code: No. All executable JavaScript is packaged with the extension.
- Permissions: use the exact explanations from `store-assets/LISTING.md`.
- Data usage: Local editing does not transmit data. Optional sign-in handles
  account identity; optional cloud and AI features transmit only the content the
  user selects for those services. If a user upgrades, Stripe collects payment
  credentials on a Stripe-hosted page and Glassware receives plan, transaction,
  invoice, renewal, and payment status. Glassware does not receive or store the
  full card number or CVC, sell data, or use it for ads.
- Paid features: optional Designer and Director cloud subscriptions range from
  $7.99 monthly to $143.99 per seat billed annually. Local capture, editing,
  saving, and export remain free.
