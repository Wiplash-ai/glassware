# Store artwork provenance

The two PNG files in this directory were generated specifically for Glassware
store materials on 2026-08-23. They contain no third-party logos, trademarks,
stock photography, or copied template artwork.

- `florist-worktable-demo.png` is the original source image edited inside the
  real Glassware UI for the five browser-store screenshots.
- `stained-glass-promo-backdrop.png` is the original abstract background used
  by the deterministic promotional-tile SVG layouts.

The approved square Glassware mark remains the first-party asset at
`public/glassware-mark.svg`. Store-ready PNGs are rendered by
`npm run store:assets`; exact typography and dimensions come from the checked-in
SVG layouts, not from generated text.
